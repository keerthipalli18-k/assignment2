# Travel & Tourism UI Template Collection

A modern frontend UI collection for travel and tourism applications.

## Applications
1. Travel Booking
2. Hotel Reservation
3. Flight Booking
4. Travel Experience

Each application contains 7 pages. Every page includes:
- index.html
- style.css
- script.js

## Features
- Responsive layouts
- Search and filtering
- Booking forms
- Checkout/payment demo
- Confirmation screens
- Profile/trip management
- Interactive buttons and JavaScript feedback
- Mobile-friendly navigation layout

## Technology
HTML5, CSS3, JavaScript

## How to Run
Open any application's page folder and double-click `index.html`.

Example:
`travel-tourism/travel-booking/home/index.html`

This is a frontend UI prototype. Payment and booking actions are demo interactions only.
